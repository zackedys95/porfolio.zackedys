CARLO BAYNO PORTFOLIO WEBSITE

FILES
- index.html: website content and structure
- style.css: design, layout and responsive styles
- script.js: mobile navigation and current year

VIEW LOCALLY
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to preview in your browser.
   (An internet connection is needed for the Google Fonts.)

PUBLISH FREE WITH GITHUB PAGES
1. Create or sign in to a free GitHub account at https://github.com/
2. Create a new PUBLIC repository named exactly:
   your-github-username.github.io
   Replace "your-github-username" with your GitHub username.
3. Upload index.html, style.css and script.js to the repository's root.
4. Open the repository's Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait a few minutes and visit:
   https://your-github-username.github.io/

BEFORE PUBLISHING
- Check the email and LinkedIn links in index.html.
- Replace the sample project artwork/cards with screenshots or images of your real work.
- Review all experience details for accuracy.
- Do not upload private client information or confidential work.

This site uses no paid hosting or paid domain. GitHub Pages provides the free
github.io address for public repositories.
